◃
Layout Registry
O(1) Map-based plugin system. 34 IDs across 8 families: base, verge-pop, sprint, onboarding, handbook, engineering, advocacy, advocacy-dense.
◆
Token-Driven Themes
15 themes × 4 style modes orthogonal matrix. Any combination is valid. Per-slide accent colors resolved from semantic palette.
↻
Runtime Content Swapping
Any content.json can be applied to any structure.js via the ControlPanel. 5-step cascading mergeDeckContent handles field normalisation.
↳
Export Pipeline
HTML single-file, image (PNG per slide), and PDF output. Run npm run export:all for full output. Storybook autodocs for visual testing.
