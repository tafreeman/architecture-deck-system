What it is

39 layouts · 16 themes · 4 style modes

A React 19 + Vite presentation platform for technical decks. Layouts are a registered plugin system — 39 IDs across 8 families, resolved through a single O(1) Map-based registry. Content is decoupled from structure: any content.json can be applied to any structure.js through a 5-step cascading merge, so decks are rebuilt from data, not copy-pasted. Every visual surface — color, type, spacing — resolves from the same token set, so 16 themes and 4 style modes compose orthogonally: any theme × any mode is a valid combination.

Registry

Layout registry

39 registered layout IDs across 8 families — base, verge-pop, sprint, onboarding, handbook, engineering, advocacy, advocacy-dense. Resolved through a Map, not a switch statement.

Tokens

Token-driven themes

16 themes × 4 style modes, an orthogonal matrix. Per-slide accent colors resolve from each theme's semantic palette — no hardcoded hex in a layout.

Content

Runtime content swapping

Any content pack can be applied to any deck structure via the control panel. A 5-step cascading merge handles field normalization across layout families.

Export

Export pipeline

Single-file HTML, per-slide PNG, and PDF output from the same deck — npm run export:all for the full pipeline.

Testing

Storybook + Vitest

Story coverage for layouts and tokens, plus a Vitest unit suite that runs in CI on every change.

Decks

6 registered decks

Current (Advocacy), AI Fluency Guidebook, Engineering, Onboarding, Verge Pop, and Studio Handbook all ship from content-registry.ts, validated at runtime with Zod.
